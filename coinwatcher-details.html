Coinwatcher App

A complete cryptocurrency tracking and portfolio management mobile application.

Live Preview View Source Code

Overview

Coinwatcher is designed for crypto enthusiasts who want to track real-time prices, set active alarms for specific price drops or hikes, and manage their total digital asset portfolio effectively.

Key Features

  • Live Tracking: Real-time price updates using REST APIs.
  • Custom Alarms: Set conditions (e.g., target price below $6,420) to get notified.
  • Portfolio Health: Visual charts to see asset history over 24h or custom timeframes.
  • Dark Theme UI: Optimized for low eye strain and premium feel.

Technologies Used

Flutter Dart REST API State Management Figma (UI/UX)
